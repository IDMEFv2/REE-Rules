### Engine and pipeline
- `patches/concerto-siem/logstash/scripts/match.rb`: `match`/`not_match` predicates were always false (`Regex` instead of `Regexp`, and
  `match` missing from the operator table; both errors silently rescued). Now returns the regex result (marker `S4S-FIX match`).
- `patches/concerto-siem/logstash/pipeline/00-my_collected.conf`: the TCP source IP was appended to `host.ip` even when the header carried an
  IP, giving `Sensor.IP = "a,b"`, rejected by Elasticsearch. Now added only when the header has none (marker `S4S-FIX sensor-ip`).

### Mappings (`logstash/idmef`)
- 57 new mapping files (309 rules), generated by `tools/gen_mappings.py` and reviewed row by row
  (`tools/mapping_review.xlsx`: 358 rows, all decided by the reviewer, 36 corrected).
- All mappings, including the 21 already published here: `"[Type][0]": "Cyber"` → `"[Type]": "Cyber"` (the indexed form created an object `{0: Cyber}` rejected
  by Elasticsearch; `normalize_array` wraps the scalar).
- ras-securid: `Server` is a hostname → `[Target][0][Hostname]` instead of `[Target][0][IP]`.
- Static audit (`tools/concerto_audit.py`, on Concerto-SIEM + these files): 75 sources, 74 mapped, 425/474 rules mapped, 0 field off-schema,
  0 value off-enum, 0 duplicate id.
